# Airline & Hotel Review Text Mining and Rating Prediction

## Project Overview

This project analyzes airline and hotel customer reviews using R. It applies data preprocessing, exploratory data analysis, sentiment analysis, and predictive modeling to extract insights from customer feedback.

The project aims to understand customer satisfaction, identify service-quality issues, analyze review sentiment, and generate actionable recommendations for improving customer experiences.

## Objectives

* Analyze airline and hotel customer reviews.
* Clean and preprocess review datasets.
* Examine rating distributions and data quality.
* Perform sentiment analysis using a lexicon-based approach.
* Explore relationships between ratings and review sentiment.
* Apply predictive modeling and correlation analysis.
* Generate actionable recommendations from customer feedback.
* Produce visualizations and analysis reports.

## Technologies Used

## Project Workflow

1. Initialize the project and load the required packages.
2. Locate and import the airline and hotel datasets.
3. Create helper functions for data preprocessing.
4. Clean and prepare the review datasets.
5. Generate data-quality reports and summary statistics.
6. Visualize rating and sentiment distributions.
7. Analyze service categories and customer feedback.
8. Perform text mining and sentiment lexicon matching.
9. Explore predictive modeling and correlation analysis.
10. Generate recommendations and save the analysis outputs.
